# 📝 React Redux Blog

> **Statut**: 🚧 Projet en cours de développement

Blog personnel fullstack moderne avec React, Redux Toolkit et Laravel API.

## 🎯 Objectifs du Projet
- ✅ Créer une API RESTful avec Laravel
- ✅ Gérer les relations complexes (articles, commentaires, catégories)

## 🛠️ Stack Technique

### Frontend
- **React** 18.x
- **Redux Toolkit** (avec Entity Adapter pour normalisation)
- **React Router** 6.x
- **Axios** pour les requêtes HTTP
- **CSS/Tailwind** (à définir)

### Backend
- **Laravel** 11.x
- **Laravel Sanctum** pour l'authentification API
- **MySQL** pour la base de données
- **API Resources** pour le formatage des réponses
